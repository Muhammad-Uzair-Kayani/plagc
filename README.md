# plagc

**plagc** is a cross-platform, fast, and lightweight 3D game engine written in modern C++.

The project is currently under active development.

> **Status:** Early development

## Overview

plagc aims to provide a focused environment for developing 3D games without carrying unnecessary engine complexity.

The project prioritizes:

- Cross-platform development
- Performance
- Lightweight design
- Modern C++
- Clear and maintainable engine development

Initial development is focused on:

- Windows
- Linux

Additional platforms may be considered as the project matures.

## Technology

Current technologies used or planned for plagc include:

| Technology | Purpose |
|---|---|
| C++ | Engine development |
| Premake | Project generation |
| GLFW | Windowing and input |
| spdlog | Logging |
| EnTT | Entity Component System |
| Ogre / Ogre-Next | Rendering |
| GLM | Mathematics |
| Jolt Physics | Physics |
| Assimp | Asset importing |
| Dear ImGui | Editor interface |

The technology stack may evolve during development.

## Project Status

plagc is currently in its foundation and early development stage.

APIs, tooling, features, and internal implementation are expected to change while the engine matures.

The repository should not yet be considered production-ready.

## Building

Build and setup instructions will be documented once the development environment and build workflow are sufficiently stable.

plagc uses **Premake** for project generation.

## Contributions

plagc is currently an **owner-maintained project**.

External code contributions are not being accepted at this stage.

This policy may change in the future as the project and contribution workflow mature.
